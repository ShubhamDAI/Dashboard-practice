## 🎯 Project Objective

To transform raw retail data into an interactive business intelligence dashboard that helps users understand sales performance, compare outlet categories, and explore trends through data-driven visualizations.

## Project Overview

This project focuses on analyzing Blinkit's sales performance, outlet characteristics, item categories, customer ratings, and product visibility using Microsoft Power BI. The interactive dashboard helps identify sales trends and compare the performance of different outlet types, sizes, and locations.

## Project Workflow

1. **Raw Data Collection** – Collected the raw Blinkit dataset for analysis.
2. **Data Walkthrough** – Explored the dataset to understand its structure, columns, data types, and business objectives.
3. **Data Connection** – Imported the dataset into Power BI.
4. **Data Cleaning & Quality Checks** – Checked for missing values, duplicates, inconsistent entries, and incorrect data types.
5. **Data Transformation** – Used Power Query to clean, format, and prepare the data for analysis.
6. **Data Modeling** – Organized tables, established relationships where required, and prepared the data model.
7. **Data Processing** – Prepared and structured the data for meaningful analysis.
8. **DAX Calculations** – Created measures for Total Sales, Average Sales, Number of Items, Average Rating, and other relevant KPIs.
9. **Charts Development & Formatting** – Developed and formatted charts, including bar charts, donut charts, line charts, and comparison tables.
10. **Dashboard Layout & Design** – Designed an interactive dashboard with KPI cards, filters, charts, and a consistent visual theme.
11. **Interactive Filters & Slicers** – Added slicers for Outlet Location Type, Outlet Size, and Item Type to explore different business scenarios.
12. **Data Analysis & Insights** – Compared sales across outlet types, item categories, outlet sizes, and establishment years.
13. **Dashboard Testing & Validation** – Checked calculations, filter interactions, chart consistency, and data accuracy.
14. **Documentation & GitHub Publishing** – Prepared project documentation and published the dashboard resources on GitHub.

## Key Dashboard Features

- Total Sales and Average Sales KPIs
- Total Number of Items and Average Rating
- Outlet Establishment Trend Analysis
- Sales Distribution by Fat Content
- Sales Analysis by Item Type
- Outlet Size and Location Analysis
- Outlet Type Performance Comparison
- Interactive slicers and dynamic visualizations
